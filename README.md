# Employee Management & Salary Analysis – SQL

## 📌 Project Overview

This project analyzes employee and department data using SQL.

The project demonstrates how SQL can be used to retrieve, filter, group, summarize, and analyze employee salary and department information.

## 🎯 Objectives

- Analyze employee salary information
- Find maximum, minimum, and average salaries
- Count employees in departments
- Analyze department-wise salary information
- Retrieve employee information using SQL queries
- Use subqueries to answer business-related questions
- Combine employee and department data using JOINs

## 🗃️ Database Tables

### Employee

Contains employee information such as:

- Employee Number
- Employee Name
- Job
- Salary
- Hire Date
- Department Number
- Manager Number

### Department

Contains department information such as:

- Department Number
- Department Name
- Location

## 📊 Analysis Performed

The project includes queries to:

- Display employee information
- Find employees earning more than a specific salary
- Sort employees based on salary
- Find the highest and lowest salary
- Calculate average salary
- Calculate total salary
- Count employees
- Calculate department-wise employee counts
- Calculate department-wise average salary
- Find departments with higher average salaries
- Retrieve employee and department details using JOINs
- Find employees earning more than the average salary
- Find employees earning more than SMITH
- Find employees working in the same department as JONES
- Generate employee and department reports

## 🛠️ Tools Used

## ▶️ How to Run

1. Download or clone this repository.
2. Open `Employee_Management.sql` in SQL Server Management Studio.
3. Execute the script.
4. The database and required tables will be created automatically.
5. Run the queries to view the analysis results.
